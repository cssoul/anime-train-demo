# 湖上铁道 · 老式小火车

日本动漫卡通风的 Three.js 可交互 3D 场景：一列老式编组沿**环湖长堤**行驶，两侧是清透的绿松石色湖水。

## 画面还原要点

对着参考视频逐帧取色后定下来的几条：

- **赛璐璐光照**：`MeshToonMaterial` + 5 级 `gradientMap`（`NearestFilter`）把连续光照量化成硬边色阶；`toneMapping = NoToneMapping` 保住高饱和动画色。
- **线稿描边**：机械物件用 `EdgesGeometry` 抽折边合成一个 `LineSegments`，比反壳描边更接近原画的"线"。
- **长堤剖面**：沿闭合曲线扫掠一条 16 点横剖面（水下泥土 → 石块护岸 → 草坡 → 道砟 → 草坡 → 石块 → 水下），顶点色分色，道砟与草坡之间只留 8cm 过渡带以保证硬边。
- **水面**：自写 `ShaderMaterial`，噪声场定水深色阶 + 双组正弦零交点画波纹白线 + 近岸浪花 + 朝阳光路；
  `aShore`（到岸线距离）按顶点烘焙，用网格加速的最近距离查询算，避免 4 万顶点 × 620 采样点卡住主线程。
- **蒸汽拖尾**：78 个 `Sprite` 池，出烟口速度只给一点点前进分量 —— 让列车开走、烟团留在原地，柱体自然被"拉"成参考图里那道向后倾的长烟。
- **编组**：DD51（橙 + 奶油 V + 全长奶油腰带）→ 青绿客车 ×2 → 暗红机车 → 橄榄客车 → 奶油客车。

## 性能

生产包实测（Chromium / Metal / 1920×1080 / DPR 1）：

| 指标 | 数值 |
| --- | --- |
| FPS | **60.2**（锁垂直同步） |
| 帧时 p50 / p95 / worst | 16.7 / 17.4 / **20.2 ms** |
| Draw Call | **142 ~ 150**（随视锥剔除浮动） |
| 三角面 | 31.2 万 |
| Shader Program | 18 |
| 纹理 | 7（全部程序化生成，零外部资源） |

> 复测方法：`npm run build && npm run preview`，再 `node scripts/showcase.mjs http://localhost:4273/ /tmp/shots`。读数取自 `window.__scene.renderer.info`，且**必须先手动渲染一帧再读**（`autoReset` 会在每帧开头清零计数器）。

60 FPS 的实现手段：

1. **按材质合批** —— `GeoBag` 把每辆车同色的零件合并成 1 个 mesh，一辆车 8 个 draw call。
2. **InstancedMesh** —— 970 根枕木、4200 朵花、5200 丛草、620 丛灌木、520 块石头、1300 根芦苇、电视杆 / 树林 / 荷叶全部各占 1 个 draw call。
3. **阴影框跟着列车走**，半径压到 78m —— 阴影相机半径是性能预算，不是构图参数。
4. **分辨率可降档**：内置 1080p / 810p / 720p 三档（`renderer.setSize` 改内部缓冲，CSS 仍铺满）。

## 交互

| 操作 | 说明 |
| --- | --- |
| 左键拖拽 / 滚轮 / 右键 | 轨道旋转 / 缩放 / 平移（自己动过镜头即切自由视角） |
| `Space` | 播放 / 暂停 |
| `F` | 贴近跟拍（车头追逐视角） |
| `A` | 自动跟拍开关 |

界面可调：**播放/暂停 · 自动跟拍 · 贴近跟拍 · 速度 0.1–3× · 一天四时（正午/黄昏/薄暮/夜色）· 四组机位 · 三档画质**，左上角实时显示分辨率 / FPS / 帧时 / Draw Call / 三角面。

> **机位预设是"相对列车的偏移"而不是固定世界坐标。**
> 固定机位只能拍到列车经过的那十几秒；做成绕环路跟着车走的极坐标偏移后，
> 任意时刻切过去都是一张有车的构图，而且背景会缓缓推移。

## 调试入口

URL 参数（都只在显式传参时生效，**不绑 `import.meta.env.DEV`**，因此能对着生产包跑）：

| 参数 | 作用 |
| --- | --- |
| `?capture=1` | 开 `preserveDrawingBuffer`，截图脚本用 |
| `?cam=x,y,z&tgt=x,y,z&fov=30` | 钉死机位，用于对着参考图逐版标定构图 |
| `?head=83.9` | 固定车头弧长，保证每次截图构图一致 |
| `?paused=1` | 启动即暂停 |

`window.__scene` 暴露 `scene / camera / renderer / controls / api / curve / cars`，可直接在控制台或自动化脚本里取证。

```bash
node scripts/probe-veg.mjs          # 例：确认实例化植被真的落在世界坐标上
node scripts/showcase.mjs http://localhost:4273/ /tmp/out
```

## 已知取舍

- 蒸汽**从最前面的 DD51 冒出**。参考视频里那柱烟其实来自编组中段（第 3 节），
  但"老式小火车一边跑一边冒烟"读起来更自然，所以把发射点放在了车头；发射点是
  `train.ts` 里挂在车上的空 `Object3D`，想改回去只需挪到对应车厢。
- 线路做成 **699m 闭合回路**而不是直线。闭合是为了让列车永远开下去、不会在画面里凭空
  出现/消失；回路做得足够大，镜头只框住一段，读起来就是参考图里那条湖上长堤。
- 水面**没有做真实反射/折射**，全部是着色器里的手绘色阶 —— 这是为了 60 FPS 的预算，
  也更贴赛璐璐动画的观感。
